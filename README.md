# Portfolio Personal

Sitio web profesional diseñado para exponer trayectoria y proyectos de desarrollo. Construido con un enfoque en código moderno, tipado estático y diseño responsivo.

## 🚀 Descripción Técnica

Este proyecto está desarrollado utilizando **TypeScript** para garantizar la robustez y escalabilidad del código cliente. La interfaz cuenta con un diseño personalizado implementado con **CSS** puro/avanzado, asegurando una experiencia de usuario fluida y adaptable a cualquier dispositivo. Incluye funcionalidad de contacto integrada mediante servicios de correo.

## 🛠 Tech Stack

* **Lenguaje Principal:** TypeScript.
* **Frontend:** React.js.
* **Estilos:** CSS3 (Diseño Responsivo / Flexbox / Grid).
* **Funcionalidad:** Integración con servicio de envío de emails (Nodemailer/API).

## ✨ Características

* **Arquitectura de Componentes:** Código modular y reutilizable.
* **Tipado Estricto:** Uso de interfaces y tipos de TypeScript para reducir errores en tiempo de ejecución.
* **UX/UI:** Diseño minimalista y navegación intuitiva.
